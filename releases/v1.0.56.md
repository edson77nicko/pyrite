# Pyrita v1.0.56

## Suporte Completo a Arquivos HTML, Renderização ao Vivo e Edição por IA

- **Renderização e Edição de HTML no Canvas Central (`HtmlEditor`)**:
  - Implementado visualizador e editor dedicado para arquivos `.html` e `.htm` com três modos de operação:
    - **Visualizar (Preview)**: Renderização segura e interativa via iframe com suporte a scripts, CSS (Tailwind via CDN), SVGs e bibliotecas modernas (Chart.js, componentes interativos).
    - **Dividido (Split View)**: Editor de código à esquerda e renderização ao vivo à direita com atualização em tempo real conforme você digita.
    - **Código (Source Code)**: Editor de código com numeração de linhas, indentação `Tab` (2 espaços), quebra de linha opcional e botão de cópia rápida.
  - Adicionado simulador de viewport responsivo para testar em **Desktop (100%)**, **Tablet (768px)** e **Mobile (375px)** com moldura centralizada.
  - Ações rápidas no cabeçalho: recarregar iframe e abrir página no navegador padrão.

- **Reconhecimento na Sidebar e Sistema de Arquivos Local**:
  - Scanner nativo do Electron e leitor web atualizados para detectar arquivos `.html` e `.htm`.
  - Ícone dedicado `<CodeXml />` em tom alaranjado (`#f97316`) na árvore de pastas da Sidebar e nas abas de navegação.
  - Novo botão de criação rápida **"Novo Arquivo HTML"** no menu principal de criação, no menu de contexto das pastas e na Paleta de Comandos (`Ctrl+P` / `Ctrl+O`).
  - Criação automática com boilerplate HTML5 moderno, responsivo e estilizado com Tailwind CSS.

- **Co-Autor IA: Edição de Código HTML em Tempo Real**:
  - Assistente IA agora detecta documentos HTML ativos e recebe instruções explícitas de código-fonte web no prompt de sistema.
  - Ao solicitar alterações, melhorias de estilo, adição de seções ou scripts, a IA atualiza diretamente o arquivo via bloco `<<<REPLACE_NOTE>>>`.
  - O código e a renderização ao vivo são sincronizados e recarregados instantaneamente na tela sem necessidade de recarregar a aplicação.
  - Novos atalhos de sugestão no chat específicos para HTML: estilização Tailwind, responsividade móvel, gráficos Chart.js e interatividade JS.
