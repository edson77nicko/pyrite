# Release v1.0.125

## Persistência Definitiva da Limpeza de Execução no Canvas

- **Correção da Persistência da Limpeza de Execuções:**
  - Corrigido o problema onde ao limpar uma execução de um fluxo, ela retornava ao sair e voltar para a página de Fluxo de Trabalho (ou ao reiniciar a aplicação).
  - Ao clicar em **"Limpar execução"**:
    1. O fluxo armazena a marcação persistente `lastClearedAt`, garantindo que execuções anteriores não reapareçam no canvas em recarregamentos ou mudanças de tela.
    2. As execuções antigas desse fluxo são desvinculadas no armazenamento persistente (`store.runs`).
    3. `selectedRunId` é redefinido para `null`, mantendo o canvas limpo e pronto para novos testes sem qualquer resquício de execuções passadas.
    4. Uma nova execução só é exibida no canvas quando o usuário clica expressamente em **Testar** ou **Executar fluxo de trabalho**.
