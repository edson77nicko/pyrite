# Pyrite v1.0.139

### Correção de Estilos de Cor e Fundo no Editor & Auto-Cura de Notas:
- **Proteção Integral de Tags HTML Inline**:
  - Correção do conflito de parsing onde trechos com cores de texto ou de fundo personalizadas (`<span style="...">` ou `<mark>`) envolvidos por formatações Markdown (itálico `*`, negrito `**`, tachado `~~`) eram escapados indevidamente para texto puro (`&lt;span style=...&gt;`), exibindo o código cru na tela com sublinhado ortográfico.
  - O processador inline agora protege as tags HTML antes de analisar os delimitadores de Markdown e interpreta o conteúdo interno de forma recursiva, preservando cores e formatações aninhadas.

- **Auto-Cura Automática de Notas Afetadas (`healCorruptedHtml`)**:
  - Implementada rotina inteligente que detecta códigos escapados em notas previamente salvas e os regenera instantaneamente para elementos visuais estilizados assim que a nota é aberta, recuperando o visual sem necessidade de edição manual.

- **Preservação em Transformações de Bloco e Colagem**:
  - A troca de tipo de bloco pelo menu lateral (parágrafo, títulos H1/H2/H3, listas e tarefas) agora preserva diretamente o `innerHTML` completo, prevenindo perda de estilos.
  - O mecanismo de colagem (`handlePaste`) passa a reconhecer e preservar trechos contendo tags e cores estilizadas.

- **Renderização no Modo Leitura e Assistente (`MarkdownRenderer`)**:
  - Suporte completo a tags estilizadas `<span style="...">` e `<mark>` no visualizador estático, garantindo consistência visual em todas as telas e modos de exibição.
