# Pyrite v1.0.114 - Correção do Loop de Renderização no Esquadrão (React Error #185)

## 🚀 Correções

### ⚡ Estabilização da Camada de Cabos SVG e Prevenção de Render Loop
- **Diagnóstico do Erro #185 (*Maximum update depth exceeded*):**
  - No módulo de Esquadrão (`SquadManagementView`), a lista de etapas do pipeline (`currentPipeline`) gerava um novo array a cada renderização.
  - O `useLayoutEffect` disparava o cálculo das curvas SVG (`setCablePaths`), que forçava um novo ciclo de renderização síncrono infinito, estourando a pilha do React.
- **Soluções Implementadas:**
  - **Memoização Estrita:** `currentPipeline`, `filteredPipeline`, `leftColumnSteps` e `rightColumnSteps` agora são memoizados com `useMemo`.
  - **Diferenciação Rasa antes do SetState:** `setCablePaths` compara as novas posições com as anteriores e não aciona re-renderização se os cabos forem idênticos.
  - **Agendamento com `requestAnimationFrame`:** A medição dos conectores no DOM agora roda fora do ciclo síncrono de render, garantindo fluidez e estabilidade total ao abrir a tela de Esquadrão.
