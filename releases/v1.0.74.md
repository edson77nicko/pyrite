# Pyrite v1.0.74 — Suporte Nativo a macOS e Pipeline Multiplataforma

Esta versão introduz suporte completo e nativo ao ecossistema **macOS**, mantendo a experiência fluida e integrada no Windows.

### 🌟 Principais novidades e melhorias:

1. **Compatibilidade Nativa com macOS**:
   - **Controles Nativos do macOS (Traffic Lights)**: Ativação automática de `titleBarStyle: 'hiddenInset'` e `trafficLightPosition` no Mac, integrando os botões nativos de fechar, minimizar e maximizar no canto superior esquerdo com alinhamento perfeito.
   - **Layout Inteligente de Abas**: Ajuste dinâmico do espaçamento inicial da barra de abas no Mac (`pl-20`) para acomodar as traffic lights do sistema sem qualquer sobreposição, e ocultação dos controles de janela do Windows no macOS.
   - **Detecção de Plataforma**: Exposição da propriedade `platform` no `electronAPI` para comunicação segura com a interface.

2. **Empacotamento e Distribuição Unificada**:
   - Configuração de build para macOS com targets DMG e ZIP de alta resolução baseados no ícone vetorial do Pyrite.
   - Suporte a release único no GitHub: instaladores de Windows (.exe) e Mac (.dmg / .zip) unificados sob a mesma versão e tag.
   - Pipeline de CI/CD via GitHub Actions para compilação simultânea em ambientes Windows e macOS.
